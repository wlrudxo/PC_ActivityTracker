Activity Tracker 사용 가이드
==============================

PC 활동을 자동으로 추적하고 태그별로 분류하여 시각화하는 개인용 생산성 도구입니다.

1. 실행
   - ActivityTracker.exe 실행
   - 시스템 트레이에 아이콘 생성됨

2. 도움말
   - 각 탭 이름 옆의 ? 아이콘을 클릭하면 해당 기능에 대한 설명을 볼 수 있습니다

3. 분류 규칙 설정
   - '미분류'로 표시되는 활동은 [태그 관리] 탭에서 분류 규칙을 추가하세요
   - 프로세스명, URL, 창 제목 등으로 자동 분류할 수 있습니다

4. Chrome URL 추적 (선택사항)
   - Chrome > 확장 프로그램 > 개발자 모드 ON
   - "압축해제된 확장 프로그램을 로드합니다" 클릭
   - chrome_extension 폴더 선택
   - chrome_extension 폴더 위치, 이름 변경 시 확장프로그램 갱신 필요

5. 종료
   - 시스템 트레이 아이콘 우클릭 > 종료
   - 설정 탭 하단 > 종료
